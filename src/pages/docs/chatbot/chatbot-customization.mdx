# Chatbot Customization

## General Customization

The **General** customization page allows users to define the key settings and behavior of their chatbot. This section is essential for tailoring the chatbot’s role and capabilities to meet specific needs. Below are the main components of the **General** page:

### 1. Chatbot Name and Role Description

- **Chatbot Name:** Users can assign a name to their chatbot, making it easily identifiable.
- **Role Description:** This is one of the most crucial settings. The description defines what the chatbot should do and how it should answer questions. It also outlines the chatbot's main role and any specific rules or guidelines it must follow when interacting with users. A well-defined description ensures the chatbot provides consistent, accurate responses.

### 2. Leads Activation

- Users can activate the **Leads** feature, which enables a form that users can fill out. This feature helps capture important information directly from chatbot interactions, enhancing lead generation and user engagement.

### 3. Helpdesk Activation

- The **Helpdesk** feature allows users to provide a list of frequently asked questions and their answers. When activated, it appears as a tab in the chatbot interface, presented in an accordion format for easy navigation. This helps users quickly find relevant information without needing to ask the chatbot directly.

### 4. Real-Time Interaction Activation

- The **Real-Time** feature, when enabled, provides a seamless way for users to escalate their inquiries. If a user asks a complicated or urgent question, they will see a button in the chatbot's message to enter their email and initiate a real-time conversation with a manager.
- Real-time interactions allow users and managers to exchange messages and images. If **Real-Time** is active, users can:
  - **Restore chat history** between the chatbot and the manager.
  - **Toggle between real-time mode** and chatting with either the chatbot or the manager.
  - Enjoy full flexibility while interacting with both the chatbot and live support.

The **General Customization** page is a crucial step to ensure the chatbot meets your specific business needs, allowing for tailored responses, enhanced user experience, and the ability to connect in real time with management when necessary.

## Customization Section

The Customization section is designed to empower users to personalize their chatbot experience significantly. This section consists of two distinct form cards, each catering to different aspects of customization. 

### 1. General Customization Card

The first card allows users to edit essential elements of their chatbot’s interface:

- **Logo Image**: Users can upload their logo to give the chatbot a personalized touch. This logo will be prominently displayed at the top of the chatbot interface.
  
- **Subtitle**: A customizable subtitle can be added, providing additional context or branding for the chatbot. This text appears below the logo and contributes to the overall aesthetic of the chatbot.

- **Initial Message**: Users can define the initial message that greets users when they first interact with the chatbot. This message sets the tone for the conversation and provides users with essential information about the chatbot's capabilities.

- **Suggested Questions**: This feature allows users to create a list of suggested questions that will be displayed beneath the initial message in the chatbot interface. Users can enter multiple suggested questions in a placeholder text area, where each line corresponds to a different question. When a user clicks on a suggested question, it will be removed from the list and presented to the chatbot for a response.

- **User Input Placeholder**: Users can also customize the placeholder text that appears in the input box. This text prompts users on what kind of information they can provide, enhancing the user experience by guiding their interaction with the chatbot.

### 2. Theme Customization Card

The second card provides a more advanced customization option, allowing users to choose between three different themes: **Light** (the default theme), **Dark**, and **Custom**. 

- **Theme Selection**: Users can switch between Light and Dark themes depending on their preferences and the visual comfort of their users. If a user selects the **Custom** theme, a series of design options will be revealed, enabling them to tailor the chatbot’s appearance to their specific needs.

#### Custom Theme

In the custom theme section, users can modify various visual elements of the chatbot’s interface by selecting colors for different components. Each section of the color customization includes:

- **Container Background**: The overall background color of the chatbot container.
- **Border Color**: The color of the chatbot's borders.
- **Primary Text Color**: The main text color for the chatbot's responses.
- **Primary Background**: The background color of the primary interface.
- **Bot Message Text Color**: The text color for messages sent by the chatbot.
- **Bot Message Background**: The background color of the chatbot’s messages.
- **Suggested Question Background**: The background color for suggested questions displayed to users.
- **User Question Background**: The background for messages sent by the user.
- **Text Color**: The general text color throughout the interface.

### Real-Time Preview Feature

A remarkable feature of the customization section is the **Real-Time Preview** functionality. As users make changes, they can instantly see how these modifications will appear in the actual chatbot interface. This interactive experience helps users make informed decisions about their customizations, ensuring that the final result meets their expectations.

### Saving Changes

Once users are satisfied with their customizations, they can click the **Save Changes** button to apply all modifications. This ensures that all changes, from the logo and subtitle to the color selections, are reflected in the live chatbot interface.

### Conclusion

The Customization section is a crucial aspect of enhancing user experience, allowing users to create a unique chatbot that aligns with their brand identity and caters to their audience. By providing options for visual customization and user engagement, this feature helps businesses optimize their chatbot interactions, leading to better user satisfaction and engagement.


## Leads Management Section

The Leads Management section allows users to effectively collect and manage input from users, enhancing their ability to capture valuable data through the chatbot. This section consists of a card with two tabs: **Add Inputs** and **Records**.

### 1. Add Inputs Tab

In the **Add Inputs** tab, users can create and customize fields to gather specific information from users. This functionality is particularly useful for capturing leads and other relevant data. 

#### Input Form

The input form contains the following features:

- **Field Name**: Users can specify a name for each input field. This is essential for understanding what information is being requested from users.

- **Required Fields**: Users can designate certain fields as required, ensuring that crucial information is not missed during data collection. If a required field is left empty, users will receive a prompt to fill it in before submission.

- **Field Customization**: Users have the flexibility to add various input fields depending on their needs and billing plan. This customization allows businesses to tailor the lead capture process according to their specific requirements.

### 2. Records Tab

The **Records** tab provides users with an overview of the data collected through the input forms. This tab is designed to streamline the management and retrieval of leads, featuring several key functionalities:

- **Search Functionality**: Users can easily search for specific records by entering keywords related to the input fields. This makes it convenient to locate particular leads or data entries without scrolling through all records.

- **Date Range Picker**: A date range picker allows users to filter records based on the date they were created or submitted. Users can select a start and end date to refine their search results, making it easier to analyze data over specific periods.

- **Export to CSV**: Users can print or export the filtered results as a CSV file. This feature is useful for further analysis or reporting, allowing users to keep records organized and accessible outside of the application.
